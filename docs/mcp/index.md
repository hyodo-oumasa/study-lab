# MCP（Model Context Protocol）

MCP は、Claude などの AI アシスタントが外部のツールやデータにアクセスするための共通の仕組み（プロトコル）です。

このページでは、MCP の考え方を学びつつ、このサイトの学習ノートを Claude から参照できる MCP サーバーを Python で自作する過程を記録します。

## このテーマで扱う予定の内容

- MCP の全体像（クライアント・サーバー・ツール・リソース）
- Python で最小の MCP サーバーを作る
- 自作サーバーを Claude Code から使う

# Claude Code

Claude Code は、Anthropic が提供する、AI によるコーディング支援のツールです。指示を受けると、ファイルを読み、コマンドを実行し、コードを書き換えるところまでを、自分で進めます。

このテーマでは、Claude Code の機能を、このサイト（study-lab）のリポジトリで実際に試しながら学び、その記録をまとめます。このサイト自体が、Claude Code と一緒に作られています。

## このテーマの進め方

各ページは、次の流れで作ります。

1. 公式ドキュメントで、機能の仕組みを確認する
2. study-lab のリポジトリで、実際に設定して、動かす
3. 分かったことと、うまくいかなかったことを、記録する

Claude Code は、機能の追加や変更が速い製品です。試験的に提供されている機能も多くあります。そのため、各ページには、確認した日と、試したときの Claude Code のバージョンを書きます。

## 機能の提供の状況

このテーマで扱う機能には、試験的に提供されているものが含まれます。動きや制限が、変わる可能性があります。

| 機能 | 提供の状況 | 扱うページ |
|---|---|---|
| Agent Teams | 試験的な機能。初期状態では無効で、設定で有効にする必要がある | 15 |
| プロジェクト | 公開ベータ。Pro と Max のプランで、順次提供されている | 16 |
| ルーティン | 研究プレビュー | 12 |

Agent Teams とプロジェクトは、複数の Claude を同時に動かすため、1 人で作業する場合よりも、利用量を多く消費します。

提供の状況は、2026 年 10 月 11 日に、公式ドキュメントで確認したものです。

## 各ページの書き方

各ページは、次の節で構成します。

| 節 | 内容 |
|---|---|
| この記事で分かること | そのページで説明する内容 |
| 用語の整理 | 専門用語と略語の意味 |
| 仕組み | 公式ドキュメントで確認した内容 |
| 実際にやってみる | study-lab で設定して、動かした手順と結果。公式ドキュメントの内容を整理するだけのページでは省く |
| うまくいかなかったこと | 想定と違ったこと、つまずいたこと。書くことがないページでは省く |
| まとめ | 要点 |
| 確認の記録 | 参照した公式ドキュメント、確認した日、Claude Code のバージョン |

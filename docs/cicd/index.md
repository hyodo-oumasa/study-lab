# GitHub Actions / CI/CD

このサイトは、GitHub Actions を使った CI/CD の仕組みで自動的に公開されています。このテーマでは、サイト自体を教材にして、CI/CD の考え方と GitHub Actions の書き方を学びます。

## CI/CD とは

| 用語 | 正式名称 | ひとことで言うと |
|---|---|---|
| CI | Continuous Integration（継続的インテグレーション） | 変更のたびに、自動でビルドやテストを行い、壊れていないかを確かめること |
| CD | Continuous Delivery / Continuous Deployment（継続的デリバリー / デプロイ） | 確かめた成果物を、自動で公開・配布できる状態にすること |

手作業で「ビルドして、確認して、アップロードして……」と繰り返す代わりに、決まった手順をコンピューターに任せることで、ミスを減らし、何度でも同じ結果を再現できるようにするのが目的です。

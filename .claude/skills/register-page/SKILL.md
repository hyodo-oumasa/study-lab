# 新しいページをサイトに登録する

対象のページ：$ARGUMENTS
（指定がなければ、`git status` で、`docs/` 以下に新しく追加された Markdown を対象にする）

次の順に行う。コミット、push、プルリクエストの作成は、この手順には含めない。

1. 対象のページの 1 行目（`# ` で始まる行）から、ページのタイトルを読む。
2. テーマのトップページ `docs/<テーマ>/index.md` の一覧で、対象のページの行を直す。
   - タイトルを、ページへのリンクにする（例：`[タイトル](./ファイル名)`。拡張子の `.md` は付けない）
   - 状態を「準備中」から「公開済み」に変える
3. サイドバー `docs/.vitepress/config.mts` の、対象のテーマのグループに、ページを追加する。
   - 番号のあるテーマでは、番号の順になる位置に入れる
4. トップページ `docs/index.md` の「新着記事」の表の、いちばん上に行を追加する。
   - 形：`| 今日の日付（YYYY-MM-DD） | テーマの名前 | [タイトル](./テーマ/ファイル名) |`
5. `npm run docs:build` を実行して、成功することを確かめる。
6. 確認用のサーバーを起動し直す。
   - 動いていれば止めてから、`npm run docs:preview -- --port 4173` を起動する
7. 次の 2 点を確かめる。
   - `http://localhost:4173/study-lab/<テーマ>/<ファイル名>` が表示される
   - テーマのトップページと、サイトのトップページに、対象のページへのリンクがある
8. 行った変更（3 か所）と、確認用の URL を、利用者に伝える。
